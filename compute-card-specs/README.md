# compute-card-specs

自动采集国内外已发布的 AI 算力卡（NPU/GPU）规格信息并整合成对比表格。

## 触发词

对话中出现以下关键词/短语时，opencode 会自动加载本 skill：

| 类别 | 触发词 |
|------|--------|
| 核心触发 | `算力卡规格`、`芯片 specs`、`算力卡参数`、`卡 specs` |
| 对比类 | `性能对比表`、`竞品算力对比`、`算力对比`、`卡片对比` |
| 字段类 | `FLOPS 对比`、`显存带宽对比`、`HBM 对比`、`互联带宽对比` |
| 厂商组合 | `昇腾 vs H100`、`910C 对比 B200`、`国产算力卡盘点` |
| 联动 | `硬件参数准备`（性能建模前）、`msModeling 硬件参数` |
| 组合示例 | `整理国内外已发布算力卡的规格对比表` |
| | `对比昇腾 950PR/950DT 和 NVIDIA B200 的 FP8 算力` |
| | `把 H20、910B、P800 的参数整理成表格` |

### 触发词设计说明（维护者参考）

- `description` frontmatter 前置关键词：`算力卡规格`、`芯片 specs`、`性能对比表`、`竞品算力对比`、`FLOPS/BW/显存对比`
- 限定语境：仅硬件规格采集/整合；性能仿真走 msmodeling-simulator，真实上板测试不归本 skill 管

## 使用示例

```
整理国内外已发布算力卡规格对比表，只要已发布的
对比昇腾 910C、H100 SXM、MI300X 的 FP16 算力和带宽
查一下 MLU590 的官方规格，校准目录数据
输出 CSV 格式，只要 FP8 和显存两列
```

## 结构

```
compute-card-specs/
├── README.md                  ← 本文件（触发词与使用说明）
├── SKILL.md                   ← 工作流定义（清单确认→采集校准→生成表格→交付）
├── scripts/
│   ├── fetch_specs.py         ← 从目录生成 md/csv/json 对比表（含校准清单）
│   └── query_catalog.py       ← 按厂商/型号/状态/字段过滤查询
└── assets/
    ├── card_catalog.json      ← 卡片目录（15+ 卡，含官方来源）
    └── table_template.md      ← 字段规范 + 口径陷阱清单
```
