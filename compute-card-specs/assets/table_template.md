# 算力卡规格对比表模板

## 表格结构

行=卡片，列=规格字段，固定列顺序：

| 厂商 | 型号 | 状态 | FP16稠密(PFLOPS) | FP16稀疏(PFLOPS) | FP8(PFLOPS) | INT8(TOPS) | 显存(GB) | 显存类型 | 带宽(TB/s) | 卡间互联 | 功耗(W) | 制程(nm) |

## 字段规范（必须遵守）

1. **单位统一**：算力列统一 PFLOPS（INT8 用 TOPS）；带宽统一 TB/s；同列不得混用
2. **稠密/稀疏**：默认填稠密值；稀疏值只在"FP16稀疏"列，加 `*` 上标
3. **FP8 缺失**：不支持 FP8 的卡填 `—`，不得填 0 或估算值
4. **显存口径**：填单卡容量（Max 配置），多芯封装（如 B200 双 die）注明单卡口径
5. **互联口径**：注明名称+带宽+单向/双向（如 `NVLink 4.0 900GB/s` 单向）
6. **状态三态**：`已发布` / `已发布未上市` / `爆料未证实`，不同状态不混排（rumor 单独成表）
7. **缺失数据**：填 `—`，脚注"官方未公开"，禁止从竞品推算

## 表头脚注（固定文案）

> 数据截止：{日期} · 状态口径：已发布/已发布未上市/爆料未证实 · `*`=稀疏算力 · `—`=官方未公开

## 来源清单（表格后固定附）

```
- **{厂商} {型号}**：{官方 URL 或 "公开报道整理，建议 Web 校准"}
```

## 口径陷阱清单（分析时逐项核对）

- NVIDIA 白皮书常给稀疏值，稠密需减半（如 H100 FP16 1979=稀疏）
- GB200 是 2×B200 的 SuperChip 口径，单 B200 需除以 2
- AMD MI300 系列常标"峰值"，注意是否为 MF16 混合精度口径
- 国产卡互联带宽多为单向/双向混标，需注明
- Gaudi 3 的 FP16=FP8 同值是官方口径，不是笔误
- 昇腾 950/960 系列采用自研 HBM（HiBL/HiZQ），带宽口径以发布会为准
