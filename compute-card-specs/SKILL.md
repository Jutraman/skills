# 算力卡规格采集与整合

自动采集国内外已发布的 AI 算力卡规格（算力、显存、带宽、互联、功耗等），整合为结构化对比表格。

## 项目背景

本 skill 维护一个**卡片目录**（`assets/card_catalog.json`），记录国内外已发布算力卡的官方规格与信息源，并按需通过 Web 检索补充/校准最新发布的产品：

- **国内**：华为昇腾（Ascend 910B/910C/950PR/950DT/960 等）、寒武纪（MLU370/590/690）、海光 DCU（K100 等）、昆仑芯（P800/BW1000 等）、摩尔线程（MTT S4000 等）、燧原、天数智芯、壁仞等
- **国外**：NVIDIA（A100/H100/H200/B200/GB200/H20 等）、AMD（MI300X/MI325X/MI355 等）、Intel（Gaudi 2/3）

**关键规格字段**：FP16/BF16 算力（含稀疏标注）、FP8/INT8 算力、显存容量/类型、HBM 带宽、卡间互联带宽、功耗、制程、发布状态。

**精度声明**：规格以厂商官方发布为准；未正式发布的型号（如下一代芯片）标注"未发布/爆料"，与已发布数据严格区分。

## 适用场景

- 用户需要国内外算力卡规格对比表（如"昇腾 vs H100 vs MI300X"）
- 用户需要某厂商全系卡的参数整理
- 用户需要最新发布的卡规格（结合 Web 检索校准）
- 性能建模/竞品分析前的硬件参数准备（可与 msmodeling-simulator 联动：输出的 `mma_ops/gp_ops/memory_bandwidth_bytes_ps` 等可直接喂给硬件参数表）

## 执行前检查

确认以下内容，缺项时向用户询问：

- **范围**：哪些厂商/型号？（默认：全部已发布；可指定如"只要昇腾和 NVIDIA"）
- **对比维度**：默认全字段；可指定如"只要 FP16 算力和带宽"
- **是否需要 Web 校准**：目录数据有固定时点，若用户要最新发布/新卡，需联网检索校准
- **输出格式**：Markdown 表格（默认）/ CSV / JSON

## 工作流程

### 阶段一：确定卡片清单

1. 读取 `assets/card_catalog.json`，按用户范围筛选卡片
2. 向用户展示筛选结果（厂商 × 型号列表）确认
3. 若用户提到目录外的卡：
   - 通过 Web 检索获取官方规格（优先厂商官网/官方白皮书/权威媒体）
   - 标注数据来源与"待校准"状态

### 阶段二：数据采集与校准

1. **本地目录优先**：`python scripts/query_catalog.py --vendor 华为 --fields fp16,memory`
2. **Web 校准**（需要时）：对每张卡检索 `"<型号> datasheet|specsheet 官方"`，逐字段核对：
   - 算力数字注意区分：稠密 vs 稀疏（sparse 通常翻倍）、FP16 vs BF16、理论峰值 vs 实测
   - 显存注意区分：HBM2e/HBM3/HBM3e、容量是否为 Max 配置
   - 互联带宽注意：单向 vs 双向、卡间 vs NVLink domain
3. 每个字段记录来源 URL；目录值与检索值冲突时，以官方源为准并提示用户目录需更新

### 阶段三：生成对比表格

1. 执行 `python scripts/fetch_specs.py --cards <id列表> --format md --output specs_table.md`，或直接按 `assets/table_template.md` 组织
2. 表格规范：
   - 行=卡片，列=规格字段（字段顺序按模板）
   - 缺失数据填 `—` 并在脚注说明"官方未公开"
   - 算力统一单位（PFLOPS），带宽统一（TB/s 或 GB/s），同列单位必须一致
   - 稀疏算力加 `*` 上标并脚注"含稀疏"
   - 未发布卡单独一张表或加列"状态"
3. 表格后附**来源清单**（每个型号的官方来源 URL）

### 阶段四：交付

- 保存表格文件到用户指定目录（默认当前目录 `specs_table.md`）
- 如用户后续要做性能仿真，提示可将表格字段映射到 msmodeling-simulator 的硬件参数（`mma_ops=FP16算力×利用率`、`memory_bandwidth_bytes_ps=HBM带宽` 等）

## 质量准则

- **可溯源**：表格中每个关键数字必须有来源；无官方来源的爆料数据必须标注"未证实"
- **口径一致**：同列同单位、同口径（稠密/稀疏、单向/双向）；混用时必须拆列
- **区分发布状态**：已发布（official）/ 已发布未上市（announced）/ 爆料（rumor）三态，不混排
- **时效声明**：注明数据截止时间，提示用户可要求 Web 校准最新数据

## 产出说明

任务完成后，告知用户：
- 对比表格文件路径（含卡片数、厂商覆盖）
- 数据来源清单与截止时间
- 目录中缺失/待校准的卡片（如有）
